1. 工程产物、包管理器和 AI 工具链新增统一的全选/反选按钮：未选择时显示“全选”，已有选择时切换为“反选”；仅作用于当前筛选结果中的可清理目录，AI 软件组会自动展开，模型、软件本体及白名单目录不参与选择。
2. 开发模块的列表底部复用下载文件夹的选择汇总胶囊，分别展示当前可选目录和已选项目的数量、大小，支持取消选择和检查清单，并适配窄窗口。
3. 各开发模块支持并行扫描、独立取消与进度回显；切换模块保留各自选择及 AI 软件展开状态，同一模块不会重复启动扫描。实际清理串行执行，完成后同步更新相关模块中的重叠结果。
4. “检查所选项目”改用与下载文件夹相同的全窗口删除确认弹窗，展示冻结的路径清单、类别、数量、大小及影响说明，取消后保留选择；清理过程复用处理遮罩、动画和完成反馈，成功项移除、失败项保留并说明原因。
5. 增加反选范围、AI 缓存批量选择、并行扫描、独立取消、重复扫描拦截及模拟清理成功/失败的回归测试，核心模型和文件系统测试增至 181 项。

需要 macOS 13.5 或更新版本及 Apple Silicon（M 系列）芯片，安装包为 `cleanMac-arm64.dmg`。

安装包采用 ad-hoc 完整性签名，尚未使用 Developer ID 证书签名或完成 Apple 公证；完整性校验通过不代表通过 Apple 信任验证，下载后仍可能被 macOS 拦截。首次打开和安全设置见 [README 安装说明](https://github.com/haoyuanwu/cleanMac#首次打开与-macos-安全设置)。
