1. 移除下载、系统缓存、重复文件及大文件扫描的最低大小门槛，图片、小文件、未知扩展名和零字节文件均可进入对应清单；应用缓存、日志和 Xcode 分析不再因大小为零排除项目，空间建议也取消 100MiB 门槛。
2. 下载文件夹仅列出直属的一级文件和文件夹，子文件不再逐项罗列；文件夹大小汇总内部内容，避免父目录与内部文件重复展示和统计。
3. 大文件页面继续按大小排序，取消原来的前 100 项截断；应用缓存扫描口径升级，旧的自动忽略记录和增量结果会失效重查，避免空缓存继续沿用旧规则被隐藏。
4. 新增并更新文件列表回归测试，覆盖全部文件类型、小文件、空文件、一级目录范围、文件夹总大小、超过 100 项的结果、空缓存、重复小文件及空 Xcode 项目；核心模型和文件系统回归测试共 144 项。

需要 macOS 13.5 或更新版本。M 系列芯片下载 `cleanMac-arm64.dmg`，Intel 芯片下载 `cleanMac-x86_64.dmg`。

安装包采用 ad-hoc 完整性签名，尚未使用 Developer ID 证书签名或完成 Apple 公证；完整性校验通过不代表通过 Apple 信任验证，下载后仍可能被 macOS 拦截。首次打开和安全设置见 [README 安装说明](https://github.com/haoyuanwu/cleanMac#首次打开与-macos-安全设置)。
