1. 新增实时网速可视化：状态栏弹窗显示上下行速度及双曲线，设置可开启独立菜单栏网速；优化两行数字的垂直居中、开关右对齐和数值换行跳动，并修复启动白屏问题。
2. 设备信息页升级为分区仪表盘：集中展示关键指标，内存趋势移入设备页，增加网络趋势、电池与存储环形占比，连接信息紧凑排列，硬件和软件明细支持展开查看。
3. 完善电脑与蓝牙设备充电状态：显示闪电图标及醒目电量，识别已配对外设插线充电；电脑电源变化后同步刷新页面与弹窗，充电时显示系统估算的充满时间，并避免对充电中的设备重复提醒。同时将文件排序选项直接展示在搜索旁，缩小控件间距。

需要 macOS 13.5 或更新版本。M 系列芯片下载 `cleanMac-arm64.dmg`，Intel 芯片下载 `cleanMac-x86_64.dmg`。

安装包采用 ad-hoc 完整性签名，尚未使用 Developer ID 证书签名或完成 Apple 公证，下载后仍可能被 macOS 拦截。首次打开和安全设置见 [README 安装说明](https://github.com/haoyuanwu/cleanMac#首次打开与-macos-安全设置)。
