1. 应用程序支持差量扫描与后台刷新，保留上次结果并显示复用、重扫数量及更新时间；新增应用占用详情，汇总本体、关联数据和已采样进程。
2. 占用变化统一卡片样式，加入范围切换与曲线动画；鼠标悬停整列即可查看时间、已用与可用空间气泡，并在空间建议中展示应用缓存增长来源。
3. 搜索入口统一为原位展开按钮，排序直接展示带图标的分类；自定义排序弹层和分段控件，统一彩色图标、功能按钮、控件高度与页面对齐。
4. 状态栏常用清理功能前置，CPU 与内存卡片逐行对齐；整理按钮放入内存卡片，退出移至标题栏，蓝牙按设备列出电量图标、百分比与充电状态。
5. 内存整理接入受限后台辅助服务，首次系统批准后无需逐次管理员弹窗；设置的系统权限增加申请、状态和移除入口，修复辅助程序启动校验路径错误导致一直整理的问题，并增加连接超时反馈。
6. 增加应用差量扫描、页面导航、整理防重入与签名约束验证，核心回归测试共 186 项；发布校验覆盖嵌入辅助程序的架构、标识符和团队签名。
