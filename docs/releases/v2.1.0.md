1. “应用与开发”新增包管理器、AI / 工具链、容器与虚拟机、工程产物四个模块，扫描常见开发缓存、模型与工具链、虚拟磁盘及项目依赖和构建目录；普通文档不作为工程产物清理。
2. AI / 工具链按软件分组展示，可展开 tmp、cache、log 等临时与缓存目录，逐项勾选或按软件选择后移到废纸篓；模型、会话、配置和软件本体保持只读，软件及缓存占用不重复汇总。
3. 四个新模块提供工具筛选、搜索、排序、详情展开和右键菜单；清理前逐目录确认范围，筛选或收起软件会取消隐藏项选择，并在执行前复核路径、符号链接及白名单。
4. 压缩四个模块结果页的汇总、筛选与底部操作区，扩大列表可见空间；统一分类、开发模块、Xcode、重复文件、磁盘地图、只读检查及概览的扫描路径、用时与真实检查次数回显。
5. 应用程序扫描在文件事件监听持续有效时复用未变化的占用快照，减少重复计算；更新或移除应用后重新核对目录与扫描结果。
6. 改进菜单栏废纸篓状态刷新，扫描期间收到刷新请求会补扫，并响应相关系统状态变化；补充 ad-hoc 构建更新后完全磁盘访问权限重新授权的说明。
7. 新增开发缓存识别、清理范围、目录保护、选择快照与占用更新等回归测试，核心模型和文件系统测试增至 175 项。

需要 macOS 13.5 或更新版本及 Apple Silicon（M 系列）芯片，安装包为 `cleanMac-arm64.dmg`。

安装包采用 ad-hoc 完整性签名，尚未使用 Developer ID 证书签名或完成 Apple 公证；完整性校验通过不代表通过 Apple 信任验证，下载后仍可能被 macOS 拦截。首次打开和安全设置见 [README 安装说明](https://github.com/haoyuanwu/cleanMac#首次打开与-macos-安全设置)。
