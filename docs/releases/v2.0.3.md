1. 卸载确认清单新增软件本体勾选框和明确的选中状态；取消软件勾选会同步排除其独有数据，保留共享数据的保护属性，全部取消后禁用卸载。
2. 修复应用占用列表漏掉新打开软件的问题，支持独立菜单栏应用和系统未提供启动时间的应用，并统一应用与进程的路径识别。
3. 修复应用退出后列表不及时更新及旧采样恢复已退出应用的问题；直接监听进程退出，移除对应列表行、趋势和异常提醒，取消退出时继续保留运行中的应用。
4. 应用占用列表右键新增正常退出和强制结束操作，强制结束前确认，执行后显示可关闭的反馈；新增整行悬停玻璃高亮和按压反馈，遵循系统减少动态效果设置。
5. 发布流程统一仅构建、校验和上传 Apple Silicon（arm64）安装包，不再生成 Intel 或 Universal 包；历史版本的 Intel 附件保留。
6. 新增卸载选择范围、共享数据保护、进程身份、退出状态及路径识别回归测试，核心模型和文件系统回归测试增至 153 项；另实测正常退出、强制结束、取消退出及延迟采样场景。

需要 macOS 13.5 或更新版本及 Apple Silicon（M 系列）芯片，安装包为 `cleanMac-arm64.dmg`。

安装包采用 ad-hoc 完整性签名，尚未使用 Developer ID 证书签名或完成 Apple 公证；完整性校验通过不代表通过 Apple 信任验证，下载后仍可能被 macOS 拦截。首次打开和安全设置见 [README 安装说明](https://github.com/haoyuanwu/cleanMac#首次打开与-macos-安全设置)。
