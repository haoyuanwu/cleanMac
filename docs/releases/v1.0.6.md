1. 修复安装包缺少完整资源签名的问题，为应用补齐 ad-hoc 完整性签名。
2. 打包脚本默认同时生成 Apple Silicon（arm64）和 Intel（x86_64）两个安装包。
3. 新增打包后的自动校验，检查 DMG 内的应用签名、版本号和芯片架构，校验失败即停止发布。

需要 macOS 13.5 或更新版本。M 系列芯片下载 `cleanMac-arm64.dmg`，Intel 芯片下载 `cleanMac-x86_64.dmg`。

当前安装包尚未使用 Developer ID 证书签名，也未完成 Apple 公证，下载后仍可能被 macOS 拦截。首次打开和“允许任何来源”的命令见 [README 安装说明](https://github.com/haoyuanwu/cleanMac#首次打开与-macos-安全设置)。
