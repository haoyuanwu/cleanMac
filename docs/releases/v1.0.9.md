1. Xcode 分析新增跨分类多选、分类与全部选择、已选数量及空间汇总和批量移到废纸篓；点击条目切换选择，分类竖条支持全选，背景按已选比例从左向右填充，并保留逐项删除校验和失败项目。
2. Xcode 清理复用应用现有的删除确认页和清理动画，完整展示待处理清单、总大小及归档和模拟器数据提示；底部汇总统一为悬浮胶囊，并优化窄窗口适配。
3. 状态栏与主页面统一使用后台持续采集的设备数据：网速和内存每秒更新，设备状态每 5 秒更新；打开页面直接显示已有数据，趋势仅保留最近一分钟所需的数据点，避免重复采集和无限积累。
4. 状态栏弹窗新增实时内存用量、占比与趋势，优化设备页网速和内存监控的视觉对齐及宽窄窗口布局；深度清理完成后保留智能清理入口。

需要 macOS 13.5 或更新版本。M 系列芯片下载 `cleanMac-arm64.dmg`，Intel 芯片下载 `cleanMac-x86_64.dmg`。

安装包采用 ad-hoc 完整性签名，尚未使用 Developer ID 证书签名或完成 Apple 公证，下载后仍可能被 macOS 拦截。首次打开和安全设置见 [README 安装说明](https://github.com/haoyuanwu/cleanMac#首次打开与-macos-安全设置)。
