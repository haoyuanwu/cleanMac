1. 智能一键清理改为独立的下一级检查页，按缓存、日志等类别分组，软件缓存进一步展示应用名称与图标，支持展开检查文件和文件夹。
2. 清理清单新增搜索、大小／名称／修改时间排序、分类和逐项勾选、恢复推荐选择、路径复制、Finder 查看及加入白名单；返回后保留本轮勾选，重新扫描会更新清单，确认清理前再次核对有效项目与白名单。
3. 首页将图形和“开始扫描”合并为单一主操作，去除重复按钮；使用独立的巡检助手与放大镜，点击后原地放大并衔接扫描动画，展示真实扫描进度及路径，取消后恢复待机，适配减少动态效果设置。
4. 更换 App 图标为纯色背景、青紫粉拼色笔记本与屏幕星光，放大笔记本占比；侧边栏七个模块按功能重新绘制图标，统一线条、留白与选中反馈，保留悬停提示和快捷键。
5. 关闭主窗口后继续驻留状态栏并隐藏 Dock 图标，通过状态栏或重新打开应用可恢复主窗口；退出命令仍可完全结束应用。
6. 增加智能清理分类归属、软件分组、搜索与排序回归测试，核心模型和文件系统回归测试共 138 项；发布流程同步收录图标设计源与生成脚本。

需要 macOS 13.5 或更新版本。M 系列芯片下载 `cleanMac-arm64.dmg`，Intel 芯片下载 `cleanMac-x86_64.dmg`。

安装包采用 ad-hoc 完整性签名，尚未使用 Developer ID 证书签名或完成 Apple 公证；完整性校验通过不代表通过 Apple 信任验证，下载后仍可能被 macOS 拦截。首次打开和安全设置见 [README 安装说明](https://github.com/haoyuanwu/cleanMac#首次打开与-macos-安全设置)。
