1. 设备信息重构为七个平级功能卡片：应用占用、CPU 与运行状态、内存状态、网络与连接、电池与电源、存储空间、系统档案；首页卡片显示实时状态摘要，详情页可返回功能列表。
2. 应用占用新增最近五分钟 CPU／内存趋势、关联进程明细、正常退出和独立的异常提醒忽略设置；设置中可恢复已忽略应用的提醒，不影响清理白名单。
3. 新增整机 CPU 使用率、用户／系统／空闲比例、最近一分钟趋势与系统热状态；内存页面增加系统压力等级、压缩内存、联动内存和交换空间趋势，未知数据明确标注。
4. 网络页面新增手动网关、DNS 和外网 HTTPS 连通性诊断，支持取消并展示耗时；仅点击诊断后发起探测，不上传设备报告。
5. 电池页面增加本机实际采集的电量曲线、供电状态变化记录与电量变化速度，可读取时展示适配器额定功率；采样间断不推算为连续使用。
6. 存储页面新增实时磁盘读写曲线、本地与外接卷容量列表，以及磁盘地图、占用变化入口；系统档案增加字段搜索、显示器分辨率与刷新率，以及脱敏报告复制和文本导出。
7. 修复高占用提醒连带打开普通状态栏面板的问题，统一两类弹窗控制；降低告警敏感度，CPU 持续高占用需确认 60 秒，突增及疑似无响应需确认 30 秒，稳定的大内存占用不再单独触发提醒，并延长启动静默与提醒冷却。
8. 一键扫描和通用扫描改为代码绘制的矢量动画，放大扫描展示区域；一键清理点击后，按钮收拢为真实进度条、巡检员插画展开、标题和路径淡入，完成与取消时连贯恢复，适配减少动态效果。
9. 修复侧边栏滚动区域裁切扫描状态圆点的问题，保留图标位置、选中背景和切换反馈；核心模型与文件系统回归测试扩展至 135 项。

需要 macOS 13.5 或更新版本。M 系列芯片下载 `cleanMac-arm64.dmg`，Intel 芯片下载 `cleanMac-x86_64.dmg`。

安装包采用 ad-hoc 完整性签名，尚未使用 Developer ID 证书签名或完成 Apple 公证；完整性校验通过不代表通过 Apple 信任验证，下载后仍可能被 macOS 拦截。首次打开和安全设置见 [README 安装说明](https://github.com/haoyuanwu/cleanMac#首次打开与-macos-安全设置)。
