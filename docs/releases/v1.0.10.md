1. 应用缓存扫描扩展至资源库中的 Containers、应用支持目录等缓存位置；浏览器和应用缓存按软件名称与图标分组，可展开查看文件夹和文件。
2. 新增缓存规则管理、无缓存目录的自动忽略列表及右键操作，支持完整复查、增量扫描与结果变化比较，减少重复扫描。
3. 扫描增加取消、权限及路径问题诊断与 JSON 导出；统一逻辑大小、磁盘占用、云端占位和跨分类去重，避免把不完整结果显示为完整扫描。
4. 常规清理优先移到废纸篓，新增清理记录与可恢复项目入口；完善卸载关联判断、运行中应用检查和共享残留提示。清空废纸篓仍为永久删除。
5. 磁盘地图采用目录列表与气泡联动布局，支持悬停信息、路径导航和选择反馈，并限制系统必需目录的选择与清理。
6. 新增启动项、浏览器隐私元数据和插件的本机只读检查，以及基于扫描结果、可解释的空间建议。
7. 重构一键清理流程和图标侧边栏：突出开始清理、扫描后的智能清理与深度扫描，设备信息独立置于末项；空间建议在扫描完成后显示。
8. 统一多色渐变与玻璃卡片，加入卡片悬停、模块展开、页面切换和扫描动画；诊断提示改为可关闭的顶部浮层，精简重复统计与路径信息，并适配减少动态效果。
9. 设备信息新增全部运行中应用的 CPU、内存占用列表、搜索和排序；检测突发高占用或疑似无响应时，通过现有状态栏入口弹出提示，可手动退出应用，强制退出需另行确认。
10. 发布脚本和 GitHub Actions 纳入 118 项核心模型与文件系统回归测试，并继续自动构建、校验 Apple Silicon 和 Intel 两种安装包。

需要 macOS 13.5 或更新版本。M 系列芯片下载 `cleanMac-arm64.dmg`，Intel 芯片下载 `cleanMac-x86_64.dmg`。

安装包采用 ad-hoc 完整性签名，尚未使用 Developer ID 证书签名或完成 Apple 公证；完整性校验通过不代表通过 Apple 信任验证，下载后仍可能被 macOS 拦截。首次打开和安全设置见 [README 安装说明](https://github.com/haoyuanwu/cleanMac#首次打开与-macos-安全设置)。
