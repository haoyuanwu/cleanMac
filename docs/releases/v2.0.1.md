1. 优化缓存、日志、下载、大文件、安装包与应用程序等列表页，将标题、大小和数量合为紧凑统计行，空间占用和扫描说明改为点击查看，为文件列表提供更多高度。
2. 下载与大文件页的时间线卡片改为横向时间筛选条；按完整扫描结果保留各时间分层，筛选后可直接切换其他范围或恢复全部。
3. 同步压缩重复文件、Xcode、白名单、启动项、插件、隐私检查、智能清理检查页和自动忽略路径列表的摘要与留白；缩小设备详情页头、磁盘地图边距，并增加应用占用列表的可用高度。
4. 应用启动后以后台优先级静默扫描应用程序列表，结果直接保留到应用管理页；每次进程启动只自动执行一次，复用用户已经开始或完成的扫描，不跳转首页或弹出完成提示，仍可手动重新扫描。
5. 发布测试脚本明确使用当前 Xcode 的 macOS SDK，发布入口增加云端构建模式，支持本机工具链更新期间由 GitHub Actions 完成测试、双架构构建和安装包校验。

需要 macOS 13.5 或更新版本。M 系列芯片下载 `cleanMac-arm64.dmg`，Intel 芯片下载 `cleanMac-x86_64.dmg`。

安装包采用 ad-hoc 完整性签名，尚未使用 Developer ID 证书签名或完成 Apple 公证；完整性校验通过不代表通过 Apple 信任验证，下载后仍可能被 macOS 拦截。首次打开和安全设置见 [README 安装说明](https://github.com/haoyuanwu/cleanMac#首次打开与-macos-安全设置)。
