# cleanMac

一款原生 macOS 空间清理工具。先扫描、查看清单，再由你决定清理哪些内容。

## 功能

- **扫描清理**：查看系统缓存、浏览器缓存、日志、应用残留和废纸篓占用；支持智能清理和逐项确认。
- **深度清理**：扩展扫描下载文件夹、大文件、安装包与应用程序，并分析重复文件和 Xcode 数据。
- **文件与应用管理**：按类别查看扫描结果、筛选文件、卸载应用；清理前展示待处理内容。
- **磁盘与设备信息**：查看空间分布、占用变化、设备信息，并设置空间增长与废纸篓提醒。
- **每日定时扫描**：可修改扫描时间或关闭；定时任务只扫描，不自动删除文件。

## 下载与安装

从 [GitHub Releases](https://github.com/haoyuanwu/cleanMac/releases/latest) 下载最新的 `cleanMac.dmg`，打开后将 `cleanMac.app` 拖入“应用程序”文件夹。

要求 **macOS 13.5 或更新版本**。部分受系统保护的位置可能需要“完全磁盘访问”或操作时的管理员授权。发布包的签名与公证状态请以对应 Release 说明为准。

## 使用方式

1. 打开 cleanMac，点击“开始清理”进行概览扫描，或选择“深度清理”。
2. 查看各类别结果与文件路径，确认后再清理。
3. 如需定时扫描，在“设置 → 定时任务”调整时间和开关。

首次完成手动完整扫描后，应用会展示一次自愿打赏提示；之后仍可从“设置 → 支持开发 → 请我喝杯咖啡”查看。打赏不影响任何清理功能。

## 隐私与安全

扫描结果保留在本机。清理前请核对待处理文件；移到废纸篓与永久删除有不同的恢复方式。定时扫描不会自动删除文件。

## 构建

进入 `cleanMac` 目录后，使用 Xcode 打开 `cleanMac.xcodeproj`，选择 `cleanMac` scheme。也可运行 `./Scripts/make_dmg.sh` 在 `cleanMac/build/cleanMac.dmg` 生成安装包。公开分发需另行使用 Developer ID 签名并完成 Apple 公证。
