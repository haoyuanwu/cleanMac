# 自定义选择与占用变化动效

1. ChoiceDropdown 复用 36 点按钮规范，入口为当前选项图标、名称与旋转箭头；点击直接显示自绘选项，不使用 Menu/Picker 的嵌套排序菜单。当前项有勾选和底色，点击即应用并关闭；支持键盘焦点、上下导航、Escape 和外部点击关闭。长筛选列表可滚动。
2. 文件排序、应用占用排序、智能清理排序、开发目录排序及所属软件/工具筛选使用该组件。排序保留原有数据处理逻辑。
3. ChoiceSegments 自绘分段底板和滑动高亮，应用于占用变化的时间范围、磁盘地图样式；支持左右键切换及选中状态标注。代码中不再保留系统 segmented 样式。
4. 占用变化切换范围与刷新快照时更新内容，曲线重新绘制、数据点淡入；点按/悬停数据点显示时间及已用/可用容量。刷新期间阻止重复请求；缓存增长路径展开有动画。减少动态效果时禁用位置与绘制动画。

验证：通过 Xcode 官方 MCP 编译、运行；实际窗口验证当天→当周切换、数据点点击，以及应用排序弹层直接显示 CPU/内存/名称，选择内存后入口名称和列表更新。测试后停止应用，未打包。

## 趋势表面与整列气泡

范围、三项摘要、趋势、增长来源和记录统一使用 StorageTimelinePanel：复用 GradientGlassSurface、18 点圆角和固定轻阴影；不再混用 CardView 白底、强调阴影与额外悬停抬升。

趋势按相邻采样点的中线划分整高命中列。悬停或点击列内任意位置选择对应样本，不依赖小圆点或全局鼠标坐标；首尾为半列，单点覆盖整个图。指示线、列底色及数据点同步高亮，气泡显示完整采样时间、已用和可用空间，左右边缘夹紧在绘图区内，依据点高度上下避让。气泡不拦截鼠标，退出列后取消悬停反馈，键盘仍可访问各列按钮。

验证：Xcode MCP 构建、启动通过；实际窗口验证中间列圆点上方空白区选择正确，左边缘气泡完整显示。最后一次右边缘截图受屏幕捕获错误影响，未完成该次截图复核。测试后停止应用，未打包。
