# 首次打开确认窗口排查

2026-11-02，基于 v2.0.1 (12)。

用户截图为 macOS 首次打开下载应用时的确认框。检查当时运行中的 cleanMac 与 CoreServicesUIAgent，采样均停在正常事件循环，未取得主线程死锁证据。cleanMac 已启动且应用列表加载完成；系统确认框的辅助功能查询超时，未能完整复现按钮无法点击，因此不能确定根因或宣称已经根治。

收紧启动行为：

- 主窗口必须可见、处于键盘焦点且应用位于前台，才安排自动应用列表扫描。
- 延迟一秒并再次检查就绪条件；失去焦点时等待下一次应用激活或主窗口获得焦点。
- 同一进程只自动开始一次；窗口关闭后重开保留扫描结果。
- 已有可见窗口时由 AppKit 处理 reopen，不额外强制激活；注册主窗口不重复设置相同激活策略。

验证：Debug 构建成功；独立测试应用的点击和键盘模块切换正常，后台应用扫描完成，关闭主窗口后可重新打开并保留列表。没有更改 Gatekeeper、隔离属性或签名信任设置；未自动确认系统安全弹窗。修正尚未发布。
