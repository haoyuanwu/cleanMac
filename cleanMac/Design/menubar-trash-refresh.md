# 状态栏废纸篓数据刷新

1. 状态栏弹窗每次显示都强制读取最新废纸篓数据，绕过普通后台查询的五分钟缓存。
2. 弹窗显示期间，在上次刷新完成后每五秒再次读取，覆盖 Finder 中移入、恢复或清空文件的变化。弹窗关闭后由 SwiftUI 取消该任务，后台仍保持原有半小时检查。
3. 监听清理记录变更与 `trashDidChange` 通知，应用内移动、恢复及清空操作会主动更新状态栏的数据。
4. 强制刷新发生在已有扫描或清空操作期间时，合并为一次待处理刷新；当前扫描完成后重扫，避免只保留变化前的结果。清空流程结束后也会强制重扫。
5. 顶部手动刷新并行更新设备和废纸篓，加载状态同时反映两者；不会因设备扫描较慢而延迟开始刷新废纸篓。

验证：arm64 Debug 构建及 156 项回归测试通过。新增三项测试覆盖五分钟内强制刷新后的大小与项目数、扫描期间多次刷新合并，以及清理和恢复通知主动刷新。测试使用注入的扫描结果及独立通知中心，没有访问或清空用户实际废纸篓。
