# 文件列表大小规则

2026-11-03：移除各文件扫描模块的最低大小门槛，列表包含零字节项目。下载页移除 1MiB、系统缓存移除 100KiB、重复文件移除 1MB、大文件页移除 100MiB 与前 100 项截断。应用缓存、日志和 Xcode 不再排除空文件或空目录；空间建议不再设 100MiB 门槛。应用缓存识别口径升级，旧自动忽略记录及增量结果会失效重查。

大小仍用于排序、汇总和比例图。零字节项目保留在磁盘地图目录列表，比例气泡/矩形无法为零面积绘图。文件类型、受保护路径、权限、白名单、重复文件每根目录 4000 候选等其他规则保持原有范围。

大文件模块沿用现有名称，按大小降序显示，说明明确包含小文件和空文件。没有自动清理新出现的文件。

下载文件夹仅展示一级直属项目，文件夹大小汇总其内容；子文件不重复出现在清单中。所有文件类型及零字节项目仍保留。
