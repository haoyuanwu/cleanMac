# 扫描与应用占用第一版

1. 扫描刷新保留当前会话的上一份结果，更新期间暂停列表操作；取消更新保留旧快照。应用程序页进入时后台差量更新，显示更新时间、复用数和重扫数；菜单提供完整重扫。重启后首次扫描仍为全量。
2. 占用变化和空间建议复用同一份应用缓存增长卡片，列出两次可比完整扫描之间的增长软件与路径；不将缓存增长表述为整盘增长的完整解释，不完整扫描不展示增长排行。
3. 应用列表双击或右键进入占用详情，展示本体、关联数据分类、识别依据和已采样进程；共享或未计量路径单独标识，详情页提供 Finder 查看入口，清理沿用原有检查流程。
4. 全部搜索输入统一复用 ExpandableSearchField，默认只占搜索图标按钮的位置，点击后在原位置变为单行输入（160–260 点宽、36 点高）；展开和收起使用 0.22 秒缓入缓出宽度动画及内容淡入淡出，跟随系统减少动态效果设置；关闭会清除条件，Escape 收起，清除按钮保留搜索焦点。筛选与排序控件垂直居中，靠右排列，展开不增加工具栏高度。
5. 重复文件的全部展开/收起合并为单个状态按钮，扫描与取消更新共用扫描操作位置。排序继续使用现有互斥分段控件或菜单。

验证：arm64 Debug 构建；核心回归；实际窗口检查应用搜索展开、筛选、应用详情和占用变化卡片。未引入生产依赖，未发布新版本。
